# Video Question Answering with CLIP + LLM

This project combines OpenAI's CLIP and a large language model (FLAN-T5 or GPT) to perform question answering on short video clips.

### 🔍 Example:
**Input Video:** A man opens a fridge and takes out a soda.  
**Question:** What does the man do after opening the fridge?  
**Answer:** He takes out a soda.
